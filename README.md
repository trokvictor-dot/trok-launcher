# Trok Launcher

Launcher moderno de **SA-MP** com visual estilo Riot Client — sem substituir nenhum arquivo do seu jogo: ele abre o `samp.exe` original da instalação que você escolher.

## Download

➡️ **[Baixar a última versão](https://github.com/trokvictor-dot/trok-launcher/releases/latest)** — Setup (instalador) ou ZIP portátil.

## O que ele faz

- **Contas** — vários nicks, cada um com avatar; troca em 2 cliques e o jogo abre com o nick certo
- **Datas** — várias instalações do GTA/SA-MP, cada uma com seu próprio User Files
- **Servidores** — favoritos com capa, logo e links oficiais; lista da internet com filtros; senha automática em servidor trancado
- **Galeria** — suas screenshots (F8) com visualizador, cópia para a área de transferência e exclusão segura
- **Extras** — cor de destaque personalizável (com seletor), bandeja do Windows, iniciar com o Windows, aviso de atualização e Discord Rich Presence

## Requisitos

- Windows 10/11
- GTA San Andreas com SA-MP instalado (qualquer versão R1/R3/R5)

Na primeira abertura, o launcher importa sozinho seu nick e seus favoritos do SA-MP original.
